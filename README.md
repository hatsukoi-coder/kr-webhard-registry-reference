## 1. 특수유형 부가통신사업자 등록번호 판독법

대한민국 「전기통신사업법」 제22조에 따라 웹하드(특수한 유형의 부가통신역무)를 합법적으로 운영하려면 과학기술정보통신부(중앙전파관리소)에 정식 등록해야 하며, 아래 형식의 등록번호가 부여됩니다.

```text
제3 - [관할 코드 2자리] - [등록·갱신 연도 2자리] - [일련번호 4자리]호
예) 제3-01-26-0001호  →  서울 관할(01) / 2026년 등록(26) / 0001호
    제3-02-15-0001호  →  부산 관할(02) / 2015년 등록(15) / 0001호
```

- **DNA 필터링 의무:** 모든 정식 등록 사업자는 「저작권법」 제104조에 따른 기술적 보호조치(DNA 필터링) 및 불법촬영물 유통 방지 조치를 의무적으로 운영합니다.
- **무필터 홍보 주의:** "필터링 없는 완전 노제휴" 등을 내세우는 사이트는 미등록 불법 도메인·악성코드 유포 위험 신호입니다.

## 3. 정식 등록 웹하드 4단계 검증 절차

1. **하단 사업자 정보 확인:** 법인명·사업자등록번호·통신판매 신고번호·특수유형 부가통신 등록번호·고객센터 유선번호 공시 여부를 확인합니다.
2. **중앙전파관리소 직접 대조:** [중앙전파관리소(crms.go.kr)](https://www.crms.go.kr/) 특수유형 부가통신사업자 현황에서 법인명 또는 등록번호를 조회합니다.
3. **보안 접속(HTTPS) 및 클린 다운로더 점검:** 공식 도메인의 HTTPS 적용 여부를 확인하고, 웹 팝업에서 출처 불명의 `.exe`나 비공식 APK 설치를 유도할 경우 즉시 중단합니다.
4. **무료포인트·정액제 약관 점검:** 순수 무료쿠폰은 결제 수단 없이 적립됩니다. '100원 체험' 등에서 카드·휴대폰 결제를 요구하면 월 자동정액제 전환 및 해지 경로를 먼저 확인해야 합니다.
